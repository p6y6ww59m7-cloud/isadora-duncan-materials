# 伊莎多拉·邓肯｜口播逐段素材清单

**[直接打开网页](https://p6y6ww59m7-cloud.github.io/isadora-duncan-materials/)**

按12个连续叙事片段整理，每段提供图片、视频、文献文字、原书截图、关系图各5项，共300个选材位置。跨段复用保留相同素材编号，包含26项图片来源、17条独立视频、29页高亮原书截图、60项文献提要与60张自制关系图。

- [下载全部素材](https://github.com/p6y6ww59m7-cloud/isadora-duncan-materials/archive/refs/heads/main.zip)
- [300项明细表](materials.csv)
- [29页高亮文献合册](highlighted-sources.pdf)

文字重点已加粗，原书相关英文已标黄。视频链接包含档案、表演者和年份；全部为学生或后人的演绎，并非邓肯本人的舞蹈录像。1902年演出、1913年事故等段落的替代画面已说明用途。图表为依据资料制作的关系示意，不是历史原图或统计数据。

## 文件

- `index.html`：完整目录与逐段清单
- `photos/`：从原书提取的照片书页
- `screenshots/`：29页高亮文献截图
- `charts/`：60张关系图，提供SVG与PNG
- `source/`：两部原书扫描PDF
- `materials.csv`、`catalog.json`：可检索的素材索引

## 来源和使用

每项素材保留具体来源链接。博物馆、图库、档案照片和视频的权利状态按来源页面说明；本仓库不对第三方材料授予统一使用许可。原书、历史照片、后人演绎及背景配图已分别标记。
